# Java Programming Assignment 2

## Overview

This assignment covers basic Java programming concepts such as methods, return types, arguments, the main method, classes, objects, constructors, inheritance, interfaces, and method overriding.

## Questions Covered

### Question 1: Return Types and Arguments

- Created a method that accepts two integer arguments.
- The method returns the sum of the two integers.
- The method is called from the `main` method.
- The result is displayed.

**Expected Output:**
```text
Sum of 5 and 10: 15
```

### Question 2: Public Static Void Main

This question explains:

```java
public static void main(String[] args)
```

The program displays:

```text
Hello, World!
```

### Question 3: Classes, Objects, and Constructors

- Created a `Student` class.
- Used `name`, `age`, and `grade` attributes.
- Created a constructor to initialize the attributes.
- Created a `Student` object.
- Displayed the student's information.

**Expected Output:**
```text
Student Information:
Name: John Doe
Age: 20
Grade: A
```

### Question 4: Inheritance, Interfaces, and Method Overriding

- Created an `Animal` superclass.
- Created a `Dog` subclass.
- Overrode the `sound()` method.
- Created a `Playable` interface.
- Implemented the `Playable` interface in the `Dog` class.

**Expected Output:**
```text
Dog makes a sound: Woof
Dog can play: Yes
```
